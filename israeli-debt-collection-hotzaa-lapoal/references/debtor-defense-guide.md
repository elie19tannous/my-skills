# Debtor Defense Guide — Responding to an Execution File

## First: note the deadline
A warning (azhara) on a shtar or a fixed-sum claim starts an opposition clock — commonly ~30 days from service. Missing it generally forfeits your right to contest the debt on the merits. Do not ignore it.

## Your options

| Option | Hebrew | When to use |
|--------|--------|-------------|
| Pay in full | תשלום מלא | You owe it and can pay; then demand file closure + lifting of restrictions |
| File opposition | התנגדות | You dispute the debt (wrong amount, not owed, forged shtar) — moves it to court |
| Request a payment order | בקשה לצו תשלומים | You owe it but need affordable instalments |
| Ability-to-pay hearing | חקירת יכולת | Present income/expenses so the Registrar sets a realistic monthly payment |
| Limited-means (mugbal emtza'im) | חייב מוגבל באמצעים | You genuinely can't meet the standard order (caps payment but adds restrictions) |
| File consolidation | איחוד תיקים | Several files from several creditors → one monthly order |
| Individual insolvency | חדלות פירעון | Total debt unmanageable even consolidated → rehabilitation + possible discharge |

## Protected income & property
- Wages/benefits have a protected minimum that cannot be garnished — verify the current floor.
- Basic household necessities are exempt from seizure.
- If a garnishment breaches the floor, file a correction motion to the Registrar with pay slips + essential-expense proof.

## Filing an opposition (checklist)
- File within the window; keep proof of the filing date.
- State grounds precisely (debt not owed, wrong sum, defense to the shtar, limitation).
- Attach evidence.
- Ask to stay enforcement pending the opposition where appropriate.

## After full payment
Request the yitrat chov printout, pay it, then file to close the file (sgirat tik) and lift ALL restrictions (exit ban, licence, bank status).
